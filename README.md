# 📊 Social Media Addiction Analysis Dashboard

## 📌 Project Description
This project focuses on analyzing **social media addiction among students** using an interactive data visualization dashboard. 

In today's digital world, students spend a significant amount of time on platforms like Instagram, TikTok, and YouTube. While these platforms are useful, excessive usage negatively impacts **academic performance, mental health, and sleep patterns**.

To better understand these patterns, this project uses **data analysis and visualization techniques** to uncover meaningful insights.

---

## 🎯 Objectives
- Analyze daily social media usage patterns among students  
- Study the impact of usage on academic performance  
- Identify the relationship between social media and mental health  
- Examine how usage affects sleep duration  
- Identify the most used social media platforms  
- Build an interactive dashboard for easy data exploration  

---

## 📊 Dataset Information
- Total Records: **705 students**
- Features include:
  - Age, Gender  
  - Country  
  - Academic Level  
  - Avg Daily Usage Hours  
  - Sleep Hours Per Night  
  - Mental Health Score (1–10)  
  - Addiction Score (1–10)  
  - Most Used Platform  
  - Academic Performance Impact  

---

## 🛠️ Tech Stack
- **Python**
- **Pandas** → Data processing  
- **Plotly Express** → Interactive visualizations  
- **Streamlit** → Web dashboard  

---

## 🚀 Features of Dashboard
- 📌 Sidebar filters (Country, Platform, Academic Level, Addiction Score)  
- 📊 KPI metrics (Total Usage, Average Usage, Student Count, Top Country)  
- 📈 Multiple interactive charts:
  - Academic performance vs usage  
  - Sleep vs usage  
  - Platform popularity  
  - Mental health impact  
  - Gender & age distribution  
  - Conflicts vs usage  
- 📉 Scatter plot (Usage vs Mental Health)  
- 📋 Data preview table  

---

## 📈 Key Insights
- 📚 Students with higher usage show **poor academic performance**  
- 😴 More social media usage leads to **less sleep**  
- 🧠 Higher usage is linked to **low mental health scores**  
- 📱 Instagram and TikTok are the most addictive platforms  
- 💬 Increased usage leads to more **social conflicts**
